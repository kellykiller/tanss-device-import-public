# Sicherheitsmeldungen

Der aktuelle gepflegte Clientstand ist 1.0.1. Der Client enthält keinen dauerhaften Zugriffsschlüssel; Zugriffe werden durch den separat betriebenen Importdienst autorisiert.

Bei einer vermuteten Schwachstelle die private Meldemöglichkeit auf der GitHub-Sicherheitsseite dieses Repositorys verwenden, sofern sie aktiviert ist. Andernfalls den Betreiber oder Maintainer über den bereits bekannten privaten Kontakt erreichen. Keine Zugangsdaten, TOTP-Seeds, Sitzungstoken, Rechnungen oder personenbezogenen Angaben in öffentliche Issues oder Pull Requests schreiben.

Das Repository enthält keine Serverquellen, Worker, Betriebsdaten oder produktiven Beispielkonfigurationen. Für Probleme des privaten Importdienstes ist dessen Betreiber zuständig.
